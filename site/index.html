TECHNICAL SYSTEM

生成・同期・検証を一つの系へ

SCENE

Schema-generated

統合シーンはEditor builderとidempotent upgradeが生成します。座席、ルールパネル、操作ボタン、検証probeを同じ定義から構築します。

NETWORK

Manual Udon sync

各ゲームはUdonSynced状態と明示的serializationを使い、ownership変更を含む実クライアント試験の対象になります。

EVIDENCE

Run-isolated logs

G3はRunToken、開始時刻、local player ID、ゲーム別同期値を解析し、同一試験の条件を満たした時だけPASSを書き込みます。

RELEASE

Upload gate

Unity、SDK、build target、G1–G3を再確認する最終ゲートを通過しない限り、リリース状態はBLOCKEDのままです。

KNOWN LIMITS

保証範囲も、明示する。

全ゲームの主要フローは実装されていますが、「全状態網羅」「改造クライアントへの秘密情報保護」「自動化された遅延参加検証」は未保証です。現状と不足はリポジトリで追跡します。
