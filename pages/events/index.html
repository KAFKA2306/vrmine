◇VRMine Game Hub

For event organizers

QRからすぐ遊べる、イベント専用ゲームHub

イベント名・主催者・CTA・質問パックを設定ファイルで切り替え、既存のAnswer Impostorをそのまま再利用する1イベント単位のPoCです。

デモを開くPoC相談・検証状況

対象

20〜100人規模の交流会、ボードゲーム会、VRコミュニティ、定期イベント。

提供範囲

ブランド表示、Answer Impostor、イベント質問パック、終了後CTA、匿名conversion event送信口。

価格

5,000〜15,000円 / event は検証中の価格仮説であり、確定価格ではありません。

計測

view_hub / start_game / complete_game / cta_click の4イベントのみ。collector URLはイベント設定で明示した場合だけ有効化します。

PoC boundary

現在の販売検証範囲

VRChat実機版はこのPoCの保証範囲に含めません。実顧客・実イベント・有償実績はコードでは生成できないため、Issue #26では技術準備と商談/実施エビデンスを分けて管理します。
