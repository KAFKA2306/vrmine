# オラパ・マイン自動問題バリアント

## 位置づけ

本実装は『オラパ・マイン』の超音波反射・色混合による推理構造を使う、VRChat向けの**自動問題バリアント**です。物理製品の完全再現ではありません。

公式情報:

- playte公式製品ページ・英語ルールPDF: https://www.playte.com/91
- アークライト日本語版製品ページ: https://arclightgames.jp/product/521apj/

公式製品は出題者がついたての裏で宝石を配置し、宝石ハンターが超音波情報から位置と向きを推理します。本実装は人間の出題者を置かず、同期されたseedから5個の宝石配置を自動生成します。

## 人数と目的

- 2–5人。
- 各プレイヤーは辺番号から超音波を発射し、出口、色、吸収の有無を記録する。
- 5個すべての宝石について座標と回転を一致させて提出したプレイヤーが勝者。
- 誤答は各席2回まで。2回誤答した席は以後提出できない。

## 操作

1. instance masterが`2P`、`3P`、`4P`、`5P`のいずれかを選ぶ。選択時に問題、ログ、誤答回数がresetされる。
2. 各プレイヤーが有効な`SEAT 1–5`を1つ選ぶ。旧生成シーンでは最初の操作時に空席へ自動参加する。
3. 自分の手番に盤面外周の番号を選び、超音波を発射する。
4. ログの入口、出口、合成色、吸収フラグを確認する。
5. `GEM 1–5`で編集対象を選ぶ。
6. `X-/X+`, `Y-/Y+`, `ROTATE`で推定配置を編集する。
7. `SUBMIT`で全5個を一括判定する。誤答時は次の有効席へ手番が移る。

手番処理は未参加席、退室済み席、誤答2回で失格した席をスキップします。退室者の席は同期ownerが解放します。

## 超音波シミュレーション

- 盤面は10×8。
- 外周に36個の入射位置を持つ。
- 宝石への衝突時に進行方向が変化し、通過した宝石色をビット合成して結果色とする。
- 吸収型に衝突すると出口なしとして記録する。
- ループまたは安全上限到達時は異常フラグとして記録する。

正確な分岐は [`OrapaMineGame.cs`](../../Assets/KafkaMade/VRMine/Runtime/Game/OrapaMineGame.cs) の `Simulate`、`Vertex`、`NextActiveSeat` を正とします。

## 公式製品との差分

| 項目 | 公式製品 | VRMine |
|---|---|---|
| 問題作成 | 人間の出題者が秘密配置 | seedによる自動配置 |
| 宝石数 | 製品同梱の宝石セット | 5個固定 |
| 秘匿 | ついたてで物理的に秘匿 | 全クライアントが同じseedから内部計算 |
| 質問回答 | 出題者が回答 | シミュレータが即時回答 |
| 勝利 | 正確な場所と向きを最初に特定 | 5個の座標・回転の完全一致 |
| 特殊宝石 | 製品ルールに従う | 製品の全宝石・全制約の完全再現ではない |

## 保証範囲

`VerifySimulation()` は代表的な反射、吸収、空席スキップ、失格席スキップを検査します。全配置・全入射・全回転の網羅試験ではありません。G3では、`puzzleSeed`と手番値が2クライアント間で同期し、所有権移管後にも再同期することをログで検査します。

公式の全配置制約、全宝石形状、全版差分を完全に反映するまで「公式ルール完全準拠」と表示しません。
