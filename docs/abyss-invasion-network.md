# 深淵侵蝕 IPルーム

深淵侵蝕のPages版は、ゲーム状態をWebSocketサーバー経由で4端末へ同期できます。サーバーを1台のPCで起動し、そのPCのIPアドレスを各端末の接続先へ入力します。

```text
task abyss:server
ws://<サーバーのIPアドレス>:8787/abyss
```

最初に接続した端末がホストとしてゲームを開始し、後から接続した端末は空きプレイヤー枠へ入ります。各プレイヤーの手番だけ、その端末の操作を有効にします。

GitHub PagesはHTTPSで配信されるため、公開URLから接続する場合はTLS対応の`wss://`エンドポイントが必要です。`ws://`のIP接続は、PagesをローカルHTTP配信している場合に使用します。
