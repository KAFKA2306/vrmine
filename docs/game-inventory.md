## 実装済みの主要フロー

### ルール可変トリックテイキング

- 3–5席、60枚のプレイカード、60番号のルールカード配列。
- 配札、ルール選択、準備、フォロー義務、勝者判定、得点、複数ラウンド。
- 参加前操作の遮断、座席重複の防止、master限定reset。
- ルール番号別の現行コード挙動を `docs/games/trick-meister-rules.md` に明示。

### オラパ・マイン自動問題バリアント

- 10×8盤、5個の自動配置宝石、36入射点。
- 反射、色合成、吸収、質問ログ、推定座標・回転、完全一致判定。
- 明示的な2–5席UIと、旧生成シーン向けの空席自動参加フォールバック。

### チェス

- 通常配置、合法手、王手、メイト、ステイルメイト。
- キャスリング、アンパッサン、4種類の昇格、投了。
- 3回同一局面・50手の申告、5回同一局面・75手の自動引き分け。
- 一般的な少駒デッドポジション判定。
